## Database domains

The 31 versioned migrations cover auth/profile and addresses; catalog/variants/taxonomy; motorcycles/fitment/garage; cart/checkout/orders/fulfillment; payments/refunds/events; reservations; promotions/usage; inventory/locations/movements/suppliers/POs; returns/warranty; reviews/wishlist; notifications/email; reports; staff/RBAC/audit/settings; media controls; search; security-definer execute ACLs; and protected cart quantity changes.

Migration `030` revokes broad execute grants from public/anonymous/authenticated roles on `SECURITY DEFINER` functions, then restores only an explicit allowlist of intended customer, permission-checked staff and read-only public RPCs. Migration `20260928101530_cart_quantity_updates.sql` revokes direct cart table mutation from anonymous/authenticated roles and adds the owner-checked, stock-checked quantity RPC. SQL tests assert those ACL boundaries. Cloud Security Advisor still reports intentionally callable authenticated business RPCs, the two intended read-only public RPCs, and the Auth leaked-password-protection setting; details are recorded in `CLOUD_SETUP.md`.

No development seed records were pushed to cloud. Local test data is confined to the local Supabase target.
